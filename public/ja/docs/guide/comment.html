HTMLコメント

JSXの{/* コメント */}は、生成HTMLへ出力されません。納品物に区切りや補足を残したい場合は、pluginComment()とCommentを使います。

出力を確認する

npm run buildで生成したHTMLを開き、コメントの位置を確認します。ブラウザの画面には表示されませんが、HTMLソースから読めるため、公開しない情報は書かないようにします。

プラグインにオプションはありません。propsの型はpluginCommentを参照してください。
