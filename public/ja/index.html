React JSX、TypeScript、Viteで100%静的なWebサイトを構築。必要な場所にだけクライアントサイドJavaScriptを追加できます。

はじめるministaとは？

MITRepositoryReleases

すべてをJSXで書き、綺麗なHTMLを生成！

静的HTMLが必要なWeb制作の現場にも、JSXのコンポーネント管理を導入したい。

独自構文を使わず、エディタサポートの優れたTypeScriptを活用したい。

minista concept by Qrac.

Features

🏗️ JSXから静的HTMLへ

JSX・TSXでページと共通パーツを記述。ファイルベースのルーティングとビルド時のデータ取得で静的HTMLを生成します。

⚡️ Viteで快適な開発

Viteの開発環境とプラグインを活用。必要なministaの機能をViteの設定から選んで組み合わせられます。

🏝️ 必要な部分だけインタラクティブに

テンプレート用のReactはブラウザに送りません。操作が必要な部分だけを、即時・表示時・アイドル時にハイドレーションできます。

🖼️ 画像の最適化

複数のサイズや次世代フォーマットでレスポンシブ画像を生成。リモート画像もダウンロードして最適化し、ローカルから配信できます。

📘 Markdown・MDXでページ制作

Markdownで本文を書き、MDXでJSXも組み合わせる。ページとしても、コンポーネントへインポートしても利用できます。

✍️ アセットを自動でバンドル

HTMLの属性からCSS・JavaScript・TypeScriptを参照するだけ。エントリーを自動で検出し、公開用にバンドルします。

🧩 SVGスプライト

SVGアイコンを最適化してスプライトに集約。CSSで色を調整しながら、同じアイコンを再利用できます。

🔍 静的サイト内検索

ビルド時に検索データを生成するため、検索サーバーは不要。言語やコンテンツごとにインデックスを分けられます。

📦 綺麗なコードで納品

HTML・CSS・JavaScriptを読みやすく整形。出力やソースファイルをZIPにまとめて、制作物を納品できます。

🤖 AIエージェントと制作

制作ルールをAIエージェントと共有。check・inspect・explainで設定やルート、ビルドの診断を確認しながら制作できます。
