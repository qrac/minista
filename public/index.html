Features

🏗️ Static HTML with JSX

Write pages and reusable components in JSX or TSX. Generate static HTML with file-based routing and data fetched at build time.

⚡️ Powered by Vite

Develop with Vite and extend your project with plugins. Choose the minista features you need through your Vite configuration.

🏝️ Interactive Islands

Keep templates free of client-side React. Hydrate only interactive components, immediately or when they become visible or idle.

🖼️ Optimized Images

Generate responsive images with modern formats and sizes. Download and optimize remote images for local delivery.

📘 Markdown and MDX

Write content in Markdown or combine it with JSX in MDX. Use either format as a page or import it into a component.

✍️ Automatic Asset Bundling

Reference CSS, JavaScript, and TypeScript in HTML attributes. minista discovers and bundles these entries for production.

🧩 SVG Sprites

Optimize SVG icons and combine them into a sprite. Reuse icons with colors controlled through CSS.

🔍 Static Site Search

Generate search data at build time with no search server. Separate indexes by language or content area.

📦 Ready for Delivery

Format HTML, CSS, and JavaScript for readability, then package output and source files into ZIP archives for delivery.

🤖 Built for AI Agents

Give coding agents a project guide and use check, inspect, and explain to examine configuration, routes, and build diagnostics.
