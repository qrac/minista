# pluginEntry

ルートパスのCSS・JavaScript・画像をビルドプロセスに乗せるプラグイン。

## Table of Contents

contents list

## v5での処理

render済みページからルートassetを`analyze` phaseで収集し、Viteが確定したoutputを`bundle`／`compose` phaseでHTMLへ反映します。renderとclient間のdataは実行可能な一時moduleではなく、build sessionのArtifact Storeで受け渡します。

## How To Use

```js title="./minista.config.js"
import { pluginEntry } from "minista"

export default {
  plugins: [pluginEntry()],
}
```

```jsx title="./src/pages/index.jsx"
import { Head } from "minista/head"

export default function () {
  return (
    <>
      <Head>
        <link rel="stylesheet" href="/src/assets/style.css" />
        <script type="module" src="/src/assets/script.ts" />
      </Head>
      <div>
        <img src="/src/assets/image.png" width={76} height={76} />
      </div>
    </>
  )
}
```
