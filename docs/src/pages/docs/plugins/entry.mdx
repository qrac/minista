# pluginEntry

This feature was integrated into `pluginSsg()` in v5. You no longer need to add the old plugin.

## Table of Contents

contents list

## Current feature

See [CSS, JS, and TS entries](/docs/guide/entry) for usage and [pluginSsg](/docs/plugins/ssg) for settings.

## Migration

Remove the `pluginEntry` import and the `pluginEntry()` call from the plugins array. There are no entry options to move to `pluginSsg()`. See [Migrating from v4 to v5](/docs/reference/migration) for details.
