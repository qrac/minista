# MDX・Markdown

MDX・Markdownは`pluginSsg`に統合され、デフォルトで利用できます。

## Table of Contents

contents list

## v5での処理

MDX／MarkdownからJavaScript moduleへの変換には`@mdx-js/mdx`を直接使用します。compilerとprocessorは最初の対象moduleが読み込まれたときに遅延ロードされ、Markdown用とMDX用のprocessorが再利用されます。

## How To Use

```js title="./minista.config.js"
import { pluginSsg } from "minista"

export default {
  plugins: [pluginSsg()],
}
```

```mdx title="./src/pages/index.mdx"
# heading

## heading2

paragraph
```

## Options

```js title="Default"
pluginSsg({
  mdx: {
    frontmatter: {
      name: "metadata",
    },
    remarkPlugins: [],
    rehypePlugins: [],
  },
})
```

`frontmatter`を除くオプションは`development`、`format`、`SourceMapGenerator`を除いた[@mdx-js/mdx](https://www.npmjs.com/package/@mdx-js/mdx)の`CompileOptions`と同一です。

## Frontmatter

フロントマターは `props` としてLayoutやPageで使用可能です。`draft` を `true` にしたページは本番ビルドから除外されます。

YAML frontmatterはデフォルトで`metadata`という名前のMDX exportへ変換されます。export名は`frontmatter.name`で変更でき、変換を無効にする場合は`frontmatter: false`を指定します。

```js title="Custom export name"
pluginSsg({
  mdx: {
    frontmatter: { name: "pageData" },
  },
})
```

```mdx title="./src/pages/index.mdx"
---
title: Index
draft: false # true = Don't build the page
---

# {props.title}
```

## Component

MDX・Markdownのファイルはレイアウトテンプレートやページテンプレート内でコンポーネントとして使用できます。

```jsx title="./src/pages/index.jsx"
import Content from "./index.mdx"

export default function () {
  return <Content />
}
```
