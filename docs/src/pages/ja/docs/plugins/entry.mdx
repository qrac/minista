# pluginEntry

この機能はv5で`pluginSsg()`へ統合しました。旧プラグインの追加は不要です。

## Table of Contents

contents list

## 現行の機能 ||current-feature||

使い方は[CSS・JS・TSのエントリー](/ja/docs/guide/entry)、設定値は[pluginSsg](/ja/docs/plugins/ssg)を参照してください。

## v4からの移行 ||migration||

`pluginEntry`のimportと、plugins配列内の`pluginEntry()`を削除します。エントリー用のオプションを`pluginSsg()`へ移す必要はありません。詳細は[v4からv5への移行](/ja/docs/reference/migration)を参照してください。
