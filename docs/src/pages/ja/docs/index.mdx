# ministaとは？

minista（ミニスタ）は、ReactのJSX・TSXとViteを使って、100%静的なHTMLを生成するスタティックサイトジェネレーター（SSG）です。

名前の「minista」は、mini static site generatorの略。

Reactのコンポーネントベースな開発体験を活かしながら、通常のHTML・CSS・JavaScriptとして扱える静的なWebサイトを作ることを目的としています。

## Reactで静的サイトを作る ||building-static-sites-with-react||

ministaでは、ページや共通パーツをReactコンポーネントとして記述します。

```jsx title="src/pages/index.jsx"
export default function () {
  return (
    <main>
      <h1>Hello, minista!</h1>
      <p>Built with React and Vite.</p>
    </main>
  )
}
```

これらのJSX・TSXはビルド時に静的なHTMLへ変換されます。

```html title="dist/index.html"
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width" />
    <title></title>
  </head>
  <body>
    <main>
      <h1>Hello, minista!</h1>
      <p>Built with React and Vite.</p>
    </main>
  </body>
</html>
```

## ViteをベースにしたSSG ||ssg-based-on-vite||

ministaはViteを開発環境とビルド基盤として利用しています。

Viteの高速な開発体験をそのまま利用し、必要に応じてプラグインを追加できます。

```js title="vite.config.js"
import { pluginSsg } from "minista"

export default {
  plugins: [pluginSsg()],
}
```

## デフォルトで静的 ||static-by-default||

ministaの出力するHTMLは、基本的に100%静的です。

クライアントサイドJavaScriptやReactのランタイムを読み込む必要はないので、次のような制作と相性が良いです。

- LP
- コーポレートサイト
- プロダクト・サービスサイト
- ドキュメントサイト
- ブログやメディア

特定のサーバーランタイムに依存せず、さまざまな静的ホスティング環境やCDNへデプロイできます。

要するに、Next.js系ではなくAstro系です。

## 必要なときだけインタラクティブ ||interactive-when-needed||

動的なUIが必要な場合は、そのコンポーネントだけをIslandとしてクライアントサイドで動かせます。

```jsx title="src/pages/index.jsx"
import { Counter } from "../components/counter"

export default function () {
  return <Counter client:load />
}
```

## 主な機能 ||main-features||

ministaには、静的サイト制作に必要な機能が用意されています。

- TypeScript
- JSX・TSXによるページとコンポーネント
- ファイルベースルーティング
- Layout
- Markdown・MDX
- 画像最適化
- SVG最適化
- SVGスプライト
- Island
- 静的サイト内検索
- HTMLの整形
- 納品用アーカイブの生成
- Viteプラグインによる拡張

各機能の使い方は[ガイド](/ja/docs/guide/)で順番に紹介します。設定値やAPIの詳細については、リファレンスと各プラグインのドキュメントを参照してください。
