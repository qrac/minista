# Node.js 26での再計測と24との比較（2026-10-05）

[同日のNode.js 24計測](v5-history-2026-10-05.md)をNode.js v26.10.0／macOS arm64で再実行した。歴史ページの表示値にはこのNode.js 26の結果を使用し、Node.js 24の記録・生データは保持する。

## 条件

- 同じマシン・一時checkout・install済み依存を使用し、Node.jsをv24.21.0からv26.10.0へ変更。現在のHEADは`38bbb2744e86f37ee31fb87422ea83400d546433`だが、前回の`8a0ece93c8c46863a3e3dcbab37ce3f510671d65`から計測対象の`packages/minista/src`／`bin`に差分はない。
- 比較対象commit・Vite／React version・fixture・cache削除・warmup・入力・sample数・中央値の採用は[24の記録](v5-history-2026-10-05.md)と同じ。v4と前回v5のbaselineも26で再測定し、異なるNode.jsの時間を混ぜて改善率を計算しない。
- buildとSearchは同時実行しない。Node.js 24の計測を先に完了し、26を後から実行した。Node.js versionの順序は交互に入れ替えていないため、24対26の差にはOSの状態・filesystem cache・時間帯の影響もあり得る。3回の中央値による観測値として扱う。

## Build

```sh
node scripts/benchmark-history-build.js "$v4Root" "$currentV5Root" "$previousV5Root"
```

fixture・versionごとにwarmupを1回、clean buildをfresh processで3回実行。CLI起動から終了までを測定し、全sampleのexit 0と`dist/index.html`出力をassertした。OSのfilesystem cacheは削除しない。

`_default`のNode.js 26での前回v5中央値は359.64ms。現在のv5は233.88msで約35.0%短縮した。遅延ロード以外の実装変更・依存更新も含む比較であり、単独の変更の効果を分離していない。

## Search index生成

```sh
node scripts/benchmark-search.js 4c7f725e0006f7fc6c4202d65f167f7f0b4391b1
```

build完了後に単独実行。Map化前のbaselineは24と同じrefから関数を抽出し、現在のv5と同じ合成解析recordを渡した。各条件・実装をfresh processで3回測定して中央値を採用。warmupなし。全sampleで生成JSONのSHA-256一致をassertし、24の同条件のhashとも一致した。

時間は入力生成・事前GCの後からindex生成完了まで。依存初期化、DOM解析、tokenizer、Vite起動、JSONシリアライズ・転送、query、React描画は含まない。

時間はms。24・26のv5列はそれぞれのNode.jsで動かしたMap化後の同じ関数。

最大規模では現在のv5が24より約10.0%短かった。一方、baselineも11,782.46 → 5,012.39ms（約57.5%短縮）と大きく変わり、Map化前後の速度比は24の162.2倍から26の76.7倍へ小さくなった。現在の実装が遅くなったことを意味しない。小規模の2条件では26の方が長く、一律の高速化も主張しない。

歴史ページは最大約77倍・約98.7%短縮と、5,012.39 → 65.39msのグラフを表示する。Searchの関数はMap化直後から変更がなく、遅延ロードの時間を含まないため、この差を非同期読み込みの効果として扱わない。

[生データ](v5-history-2026-10-05-node26-search.jsonl)に全sampleの時間・heap差分・maxRSS・SHA-256を保存した。メモリ削減や他環境で同じ比率になることは主張しない。
